# 智能健身教练

通过 USB 摄像头实时识别 **17 个人体关键点**，对 **深蹲 / 开合跳 / 高抬腿 / 弓步蹲 / 侧平举 / 马步蹲（计时）** 六种动作进行判定：
**计次/计时 + 实时纠错 + TTS 语音鼓励**，MIPI 屏实时预览。

运行环境：RK3576 开发板（Debian 13，Python 3.13，GNOME Wayland）

## 硬件需求

| 硬件 | 要求 / 说明 |
|---|---|
| **RK3576 开发板（QUECPI M2）** | 核心板，板载 **6 TOPS NPU**（YOLO11n-pose fp16 推理约 55ms/帧）；Debian 13 + GNOME Wayland 系统；板载 WiFi/蓝牙（AIC 组合芯，蓝牙耳机可用） |
| **USB 摄像头** | 640x480 即可（YUYV 定焦机型实测可用）；插上自动发现（USB 优先、实测出图），换摄像头免改配置；**固定在三脚架/支架上**，对准全身或半身站位 |
| **显示屏** | MIPI 触摸屏（本项目默认，无框圆角窗口自适应屏幕尺寸）；HDMI 屏同样可用 |
| **喇叭** | 接板载 ES8389 模拟输出口（语音直出）；或蓝牙音箱/耳机（走 PipeWire 系统路由，自动跟随系统输出设备） |
| **USB 数据线** | 连开发主机 adb 部署调试用（板子支持 WiFi 时也可无线 adb / ssh） |

> 权限提示：普通用户需加入 `video`、`audio` 组才能使用摄像头和声卡
> （`sudo usermod -aG video,audio 用户名` 后重新登录）；无需键鼠，adb/ssh 调试即可。

## 效果

- 摄像头 640x480@30fps 采集，NPU 推理 **约 55ms/帧（≈18 FPS）**，整链路 UI 显示约 14 FPS
- 左侧实时视频（**镜像自拍模式** + **数字变焦 0.5~3x**）+ 骨架叠加；
  右侧：动作切换 / 大字号计数 / 阶段与纠错提示 / FPS
- **无框弧形圆角窗口**（26px 圆角 + 渐变底 + 漫画描边），Esc 键退出
- 变焦：按钮 `− ＋ 1.0x` 或键盘 `+ / - / 0`，范围 **0.5~3x**（步进 0.25）；
  放大=中心裁剪后送推理（人远时识别更稳）；缩小仅加黑边便于确认取景——
  USB 摄像头定焦定视野，缩小看不到镜头外的内容，脚没入镜请后退或下调摄像头角度
- 语音（微软晓晓神经语音合成，热情女声）：数字播报（1-30）、每 10 个里程碑鼓励、
  动作纠错提示（6s 冷却防刷屏）；**没人时不催促**，人回到画面才说一次"已经看到你了"
- 动作通过**下拉框选择**（6 种，点击下拉框任意位置弹出），切换有 1.5s 冷却 + 重复选择忽略
  （防止运动时手掌扫过触摸屏误切换）；马步蹲为**计时模式**（大数字显示坚持秒数，
  每 10/20/30/45/60 秒语音里程碑）
- **中英双语**：右上角 `EN / 中` 按钮一键切换，UI 文案 + 动作阶段提示 + 语音（中文晓晓 / 英文 Jenny）
  三方同步；初始语言可用环境变量 `FITNESS_LANG=zh|en` 指定
- **训练门闸**：启动后处于**待机**状态（只预览不计次），按「▶ 开始训练」才开始记录；
  训练中可随时**暂停/继续**（次数冻结保留）——不按开始，躺着/走近屏幕/随意走动等一切
  干扰都不会计入。**归零**按钮可随时把次数/计时清零重新开始

## 使用指南（使用者请看这里）

### 开始之前：站位和环境

- **站多远**：离摄像头 **2~4 米**比较稳（太远了识别会变差）
- **光线**：正常室内照明即可；避免逆光（背后是窗/灯）和昏暗环境
- **朝向**：正面对着摄像头做动作
- **入镜范围**：
  - 深蹲 → 上半身到大腿入镜就能计数（脚踝被挡住时会自动换用髋部角度判断）
  - 开合跳 → 需要**全身**入镜（要看脚的距离和手的高度）
- 摄像头是定焦的，**人没入镜只能往后退或调整摄像头角度**（缩小画面不会看到镜头外的东西）

### 动作怎么才算「一次」

**深蹲**（大白话：屁股往后坐，坐到大腿差不多和地面平行，再站直）：
- 蹲下去要蹲够深：**大腿蹲到接近与地面平行**（膝角约 115°，也就是大腿小腿夹角弯到 115° 左右）
- 站起来要站直：身体回到挺直站立（膝角超过 145°）
- 蹲得不够深 → 不计次，屏幕会告诉你原因，比如「上次蹲不够深(121°) 未计次」
- 常见纠错提示：**膝盖不要内扣**（膝盖向内歪）、**背部挺直**（弯腰驼背前倾）

**开合跳**（大白话：跳起来时手脚打开，落地时手脚收回）：
- 打开：双脚跳开**明显比肩宽**（约 1.35 倍肩宽以上），同时**双手举过头顶**
- 收回：双脚并拢，手放下来
- 一个完整的「并拢 → 打开」算一次
- 节奏别太快：**快于每秒 1 次可能漏计**（受帧率限制）
- 常见纠错提示：**手臂要举过头顶**、**双脚再分开一些**

**高抬腿**（大白话：原地跑步，膝盖往上顶）：
- 膝盖抬到**髋部附近**（不用抬到完全水平，普通人标准）
- 左右脚交替各算一次
- 节奏别太快：**快于每秒 2 次可能漏计**（受帧率限制）
- 常见纠错提示：**膝盖再抬高一点**

**弓步蹲**（大白话：一条腿往前迈一大步往下蹲，再站起来换边）：
- 下蹲时前腿弯曲明显（弯曲腿膝角约 135° 以下，不用蹲到大腿平行）
- 蹲下去再站直算一次，左右腿都算
- 常见纠错提示：**再蹲低一点**

**侧平举**（大白话：双臂从身体两侧抬到肩膀高度，再放下）：
- 双手同时抬到**肩膀高度附近**（不用完全举平，普通人标准）
- 举起→放下算一次
- 常见纠错提示：**双臂一起抬**、**手臂抬平到肩膀高度**

**马步蹲（计时）**（大白话：双脚分开比肩宽，往下蹲并保持住）：
- 双脚分开约 1.5 倍肩宽，膝盖弯到约 135° 以下**保持住**就开始计时
- 中途站起来计时暂停，再蹲下继续累计（不白费）
- 每 10/20/30/45/60 秒语音播报里程碑
- 常见纠错提示：**双脚再分开一点**、**再蹲低一点**

### 界面操作

| 操作 | 方式 |
|---|---|
| 启动 | 文件管理器双击 `code/ai-fitness-coach` |
| 退出 | 键盘 **Esc**（圆角窗口没有右上角关闭按钮） |
| **开始训练** | 蓝色 **▶ 开始训练** 按钮——启动后是**待机**状态（只预览不计次），按了才开始记录 |
| **暂停 / 继续** | 训练中按钮变橙色 **暂停**，按一下冻结次数；再按 **▶ 继续训练** 接着累计 |
| **归零** | 绿色 **归零** 按钮，次数/计时清零重新开始 |
| 变焦 | 界面 `− ＋` 按钮或键盘 `+ / - / 0`（0.5~3 倍） |
| 切换动作 | 右侧**下拉框**选择（6 种动作，点任意位置弹出）；马步蹲显示坚持秒数，其余显示次数 |
| 切换语言 | 右上角 **EN / 中** 按钮（界面、提示、语音同步切换） |

- 语音会自动播报：模式名、321 开始、每次计数、每 10 个的鼓励、动作纠错提醒
- 再双击一次启动器 = 重启应用（会自动先停掉旧实例）
- **为什么要按「开始训练」**：待机/暂停时画面照常预览（方便你调整站位），
  但任何动作都不会被计入——躺下休息、走近屏幕看数据、路过镜头都影响不到你的成绩

## 板上部署与运行

整个流程涉及两台机器，先分清角色：

| 机器 | 是什么 | 干什么 |
|---|---|---|
| **开发主机** | 你的 PC（项目源码所在电脑） | 生成安装包、通过 adb 推给板子 |
| **开发板** | RK3576 板子（USB 线连主机，adb 可识别） | 安装、运行应用 |

### 方式一：一键安装包（推荐）

分 3 步，第 1、2 步在**主机**上做，第 3 步在**板子上**做：

**第 1 步（主机）：拿到一键安装包**

两种途径任选其一：

- **直接下载（省事）**：从 [Releases](https://github.com/MAODEHUANXIANG/demo-ai-fitness-coach/releases) 页面下载 `ai-fitness-coach-installer.run`（约 220MB，已内置全部运行环境）
- **自己构建**：把项目里的 code + models + audio + runtime 全部压缩进一个自解压文件（约 200MB）：

```bash
cd "/home/q/project/Demo/AI-Fitness-Coach"
tools/make_run_pack.sh
# 完成后产物在: dist/ai-fitness-coach-installer.run
```

**第 2 步（主机）：通过 adb 推到板子上**

```bash
adb push dist/ai-fitness-coach-installer.run /home/q/
adb shell chown q:q /home/q/ai-fitness-coach-installer.run
```

**第 3 步（板上）：执行安装包，解压出完整应用**

哪条命令都不用记——取决于你想给谁用（二选一）：

```bash
# A. 给普通用户 q 用（推荐）→ 装到 /home/q/ai-fitness-coach
adb shell su - q -c '/home/q/ai-fitness-coach-installer.run'

# B. 给 root 用 → 装到 /root/ai-fitness-coach
adb shell /home/q/ai-fitness-coach-installer.run
```

（上面两条是在主机上通过 adb 敲的；也可以直接在板子的终端里登录对应用户后执行
`/home/q/ai-fitness-coach-installer.run`，效果一样。安装包重复执行会自动清掉旧版重装。）

**安装完成后怎么打开（板子上，无需终端）：**

打开板子的文件管理器 → 进入 `ai-fitness-coach/code/` →
**双击 `ai-fitness-coach`** 就能运行。

`ai-fitness-coach` 不是脚本而是编译好的二进制（2MB 静态 ELF，源码 `tools/launcher/main.go`），
所以 GNOME 双击它**直接执行**，不会弹「运行还是显示？」的对话框：

- 重复双击 = 自动重启（会先停掉旧进程，摄像头/NPU 不会被两个进程抢）
- 没有终端窗口，日志自动写在 `~/.local/state/fitness-coach/app.log`
- 终端里跑 `code/run.sh` 是等价方式（调试看输出用）

## 算法与实现要点

**姿态模型**：用户提供的 [MediaPipe](https://github.com/google-ai-edge/mediapipe)
PyPI 无 aarch64 Linux wheel、板上源码编译不现实（此前调研结论），故采用
[Ultralytics YOLO11n-pose](https://github.com/ultralytics/assets)（同为业界主流、
原生 17 关键点 COCO 格式）：
- ONNX 版作为 CPU 兜底（onnxruntime aarch64 wheel）
- 转换 RKNN fp16 跑板载 6 TOPS NPU（不量化，关键点坐标对量化敏感）
- 板上无 rknnlite cp313 包 → 自写 ctypes 绑定直调 librknnrt.so C API

**深蹲判定**（左右膝平均角度状态机）：
- 站立(>145°) → 下蹲(<125°) → 站起(>145°) 完成一次；入蹲 3 帧/起身 2 帧确认防抖
- 计次要求最低膝角 < 115°（蹲到位），否则提示"下蹲再深一点"且不计次
- 弯腰门闸：躯干前倾 >55° 时不允许进入下蹲（弯腰不是蹲，防误计）
- 踝关节不可见时自动切换**髋角兜底模式**（肩-髋-膝，阈值同步放宽）；
  膝盖也出镜时进入**高度兜底模式**（肩+髋可见即可）：用髋部相对站立基线的
  下沉量计次（入闸 0.65 倍躯干长/出闸 0.22，低位滞留 4s 重置基线）
- 纠错：膝盖相对髋-踝连线内偏 > 9%（持续 6 帧）→"膝盖不要内扣"；
  躯干前倾 > 55° →"背部挺直"

**开合跳判定**（肩宽归一化 + 连续 3 帧确认防抖）：
- 打开：脚距 > 1.35 肩宽 且 双腕高于鼻尖；并拢：脚距 < 0.6 肩宽
- 启动就位确认：先观察到并拢姿势（连续 3 帧）才开始计次，
  防止启动时人已张开直接计 1 次
- 完整"并拢→打开"计 1 次
- 纠错：打开时腕未过顶 →"手臂要举过头顶"；脚距不足 →"双脚再分开一些"

**高抬腿判定**（膝高比例状态机，普通人标准）：
- 计次：膝抬到「髋下 0.5 躯干长」以内，且抬起侧脚踝明显高于另一侧（排除深蹲误判）
- 抬起→落地为一次，**左右腿独立状态机**交替各计 1（同一条腿抬两次只算一次还原后才能再计）
- 专属阈值：关键点置信度阈值 0.15（比其他动作的 0.25 宽松——动作幅度大关键点易丢）；
  膝盖位置另有解剖学范围校验（置信度 ≥0.30 + y 坐标合理才采信），静立噪声不会自增计数
- 丢帧三态处理：膝盖不可见时清票不做证据，防止跨丢帧拼凑出一次
- 纠错：膝在髋下 0.55~0.9 躯干长之间持续 ~0.5s →"膝盖再抬高一点"

**弓步蹲判定**（双膝角差 + 弯曲腿角度状态机）：
- 弓步：任一膝角 <140° 或双膝角差 >25°（持续 2 帧）；站立：双膝 >150° 且角差 <12°
- 计次要求弯曲腿最低膝角 <135°（普通人标准，体育级 90~100° 过严）
- 踝不可见时降级髋角判定；纠错：不够低 →"再蹲低一点"

**侧平举判定**（腕高/躯干长比例状态机，普通人标准）：
- 举起：双腕同时到「肩下 0.15 躯干长」以内（体育级"完全水平"过严）
- 放下：双腕回落肩下 0.4 躯干长（滞回防抖动）；举起→放下计 1 次
- 丢帧清票：中途关键点丢失时累计票数清零，防止跨丢帧拼凑计次
- 纠错：单臂先举不同步 →"双臂一起抬"；半程停留 →"手臂抬平"

**马步蹲判定（计时模式）**：
- 保持条件：平均膝角 <135°（普通人标准，武术级 90~100° 过严）且踝距 > 1.1 肩宽
- 中断不计损失：站起时本段时间并入累计，再蹲下继续
- 里程碑 10/20/30/45/60 秒语音播报；纠错：宽距不足 →"双脚再分开"；膝角不够 →"再蹲低一点"

## 已知限制

- 摄像头 YUYV 无 MJPEG，640x480 实际带宽受限；检测率依赖人距镜头 1.5-3m、正身
- 开合跳节奏很快时（>1 次/秒）可能漏计（推理 18fps + 3 帧确认）
- 深蹲高度兜底模式无法区分"真深蹲"和"蹲低看屏幕"（走近镜头蹲下可能计 1 次）——
  属运动学原理性限制，建议通过训练门闸规避（看数据前先暂停）
- conda PySide6 体积大（985MB）；如需精简可删 libLLVM/libclang（约 340MB，仅 QtUiTools 用）
